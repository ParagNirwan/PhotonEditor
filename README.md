# PhotonEditor

An Android photo-editing application project.

## Technology

The repository uses Gradle for its Android build. Open the project in Android Studio with a compatible Android SDK installed.

## Build and run

1. Clone the repository.
2. Open the project in Android Studio and allow Gradle synchronization to complete.
3. Select an available Android emulator or connected device.
4. Run the app from Android Studio.

Inspect the Gradle configuration for the configured Android Gradle Plugin, SDK levels, and build variants.

## Project status

Before publishing a release, document supported Android versions and editing features, add screenshots, and verify that build artifacts, IDE-specific files, and signing credentials are not committed.
